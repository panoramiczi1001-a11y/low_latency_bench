# 3.2 Linux 运行时分配与虚拟内存

对应的读书笔记：`QD学习笔记.md` 3.2。

## 实验清单

| 文件 | 目的 |
|---|---|
| `exp5.cpp` | 随机指针追逐扫工作集，对比 4 KiB 页与 2 MiB 大页，判断那个台阶是否来自 TLB |

## 怎么跑

```bash
make
taskset -c 0 ./exp5
```

## 已知限制

- 大页需要系统有可用的大页池（`/proc/meminfo` 里的 HugePages_Total）。
  申请不到时会静默退化成普通页，结果看起来「大页没用」——先确认真的用上了。
- 容器环境下 `mmap` 的返回和裸机不同，跨环境对比要注明。
