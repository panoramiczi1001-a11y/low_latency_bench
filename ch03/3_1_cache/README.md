# 3.1 处理器缓存与内存层次

对应的读书笔记：`QD学习笔记.md` 附录「缓存、内存与一致性」。

## 实验清单

| 文件 | 目的 |
|---|---|
| `cache_probe.cpp` | 两次扫：按步长扫出 cache line 大小；按工作集扫出 L1/L2/L3 容量 |
| `exp1.cpp` | 线性指针追逐，8 MiB 数组、步长 64 B，量单次跳转耗时 |
| `exp2.cpp` | 与 exp1 相同，但把链打乱——用来打败硬件预取器 |
| `exp3.cpp` | 线性追逐 + 扫工作集（8–256 MiB），看是平滑上升还是台阶 |
| `exp4.cpp` | 二维数组行优先 vs 列优先；另量一遍缺页代价 |
| `exp6.cpp` | 伪共享：两个计数器放在同一 / 不同 cache line |
| `exp7.cpp` | 换不同核配对跑伪共享，量「一次线传输」值多少纳秒 |
| `win_chase.cpp` / `win_share.cpp` | 同上两件事的 Windows 版本（需要 MSVC，未纳入 Linux 构建） |

## 怎么跑

```bash
make
taskset -c 0 ./cache_probe    # 绑核，避免迁移
```

伪共享相关（exp6/exp7）要多核，不要绑单核。

## 已知限制

- 工作集 16 MiB 附近的边界在虚拟机和裸机上可能差五成，测出的「边界值」只代表当时状态。
- `win_*` 两个文件依赖 `windows.h`，Linux 下只编译其余目标。
